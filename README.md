# 혼자 합주실

악기를 하나씩 녹음해 겹쳐 쌓고 믹싱하는 웹 녹음실이에요. 바이올린·클라리넷·기타처럼 혼자 여러 악기를 녹음해 한 곡으로 합칠 수 있어요.

**열기:** https://htcho-max.github.io/hapju/ (태블릿·휴대폰에서 홈 화면에 추가하면 앱처럼 써요)

## 할 수 있는 것
- 트랙마다 녹음, 다른 트랙을 들으며 겹쳐 녹음, 테이크 쌓기·고르기
- 녹음 지연 재기·보정, 메트로놈과 카운트인
- 클립 옮기기·다듬기·페이드, 되돌리기
- 트랙별 리버브·EQ·좌우·볼륨, 울림 공간, 리미터
- WAV로 내보내기·공유, 휴대폰 녹음 파일 불러오기
- 튜너 (바이올린·기타 개방현, B♭ 클라리넷)
- 구간 반복 연습·반복 녹음(회마다 테이크), 음높이 그대로 50~100% 느리게 듣기
- 여기서 나누기 → 구간마다 다른 테이크 고르기·비우기 (좋은 부분끼리 잇기)
- 소리 정리: 음량 자동 맞춤, 잡음 줄이기
- MP3(작은 파일)·WAV로 보내기
- 작업은 이 기기(브라우저)에 자동 저장, 백업 파일(.hapju)로 내보내기·가져오기

## 기술
빌드 없는 단일 `index.html`과 서비스 워커(`sw.js`), 웹 앱 매니페스트로 되어 있어요. 마이크를 쓰려면 HTTPS 주소에서 열어야 해요.

## 시험
`tools/t2.mjs`: 헤드리스 Chrome과 가짜 마이크로 녹음·반복 녹음·나누기·느리게·소리 정리·MP3·백업을 확인해요 (`node tools/t2.mjs`, 환경 경로는 파일 위쪽에서 바꿔요).
